# MM Plugin (美图插件)

一个功能丰富的AstrBot美图发送插件，支持多种图片类型和触发方式。

## ✨ 功能特性

### 🖼️ 图片功能
- **美女图片**: 发送 `/666` 或包含 "666" 关键词，随机获取美女图片
- **黑丝图片**: 发送 `/黑丝` 或包含 "黑丝" 关键词
- **JK图片**: 发送 `/jk` 或包含 "jk" 关键词  
- **诱惑图片**: 发送 `/诱惑` 或包含 "诱惑" 关键词
- **白丝图片**: 发送 `/白丝` 或包含 "白丝" 关键词

### 🎬 视频功能 (配置中)
插件配置文件中还包含了多种视频接口，支持：
- 帅哥视频、怼人视频、神回复视频
- 慢摇视频、白丝视频、黑丝视频
- 吊带视频、清纯视频、玉足视频
- 汉服视频、COS视频、甜妹视频等

## 🔧 配置选项

### 基础配置
```json
{
  "enable": true,           // 是否启用插件
  "triggers": ["666", "黑丝"]  // 触发关键词列表
}
```

### 视频接口配置
```json
{
  "video_apis": {
    "帅哥视频": "http://api.yujn.cn/api/xgg.php?type=json",
    "黑丝视频": "http://api.yujn.cn/api/heisis.php?type=json",
    // ... 更多接口
  }
}
```

## 📖 使用方法

### 命令触发
- `/666` - 发送美女图片
- `/黑丝` - 发送黑丝图片  
- `/jk` - 发送JK图片
- `/诱惑` - 发送诱惑图片
- `/白丝` - 发送白丝图片

### 关键词触发 ⭐
**插件现在支持关键词触发！** 在消息中包含以下关键词也会触发相应功能：
- "666" → 美女图片
- "黑丝" → 黑丝图片
- "jk" → JK图片
- "诱惑" → 诱惑图片
- "白丝" → 白丝图片

**示例**：
- 发送 "今天天气真好666" → 触发美女图片
- 发送 "黑丝小姐姐真好看" → 触发黑丝图片
- 发送 "jk制服很可爱" → 触发JK图片

## 🛠️ 技术实现

### 核心特性
- **多API支持**: 集成多个图片API，提高成功率
- **重定向处理**: 自动处理HTTP重定向，兼容更多API
- **错误容错**: API失败时自动尝试备用接口
- **临时文件管理**: 自动创建和清理临时图片文件
- **详细日志**: 完整的调试日志记录
- **双重触发**: 同时支持命令触发和关键词触发

### API接口
- **美女图片**: 4个备用API接口
- **其他类型**: 每个类型对应专门的API接口
- **响应处理**: 支持直接图片和JSON格式响应

### 兼容性
- 支持私聊和群聊
- 兼容AstrBot 3.4.0+版本
- 支持所有AstrBot支持的平台

## 📝 依赖要求

- `aiohttp` - 异步HTTP请求
- `tempfile` - 临时文件处理
- `random` - 随机选择API

## 🔍 调试信息

插件提供详细的调试日志，包括：
