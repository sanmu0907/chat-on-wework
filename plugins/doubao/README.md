# Doubao 插件

## 简介

Doubao 是一个适配 chatgpt-on-wechat / dify-on-wechat 框架的豆包 AI 插件，为微信机器人提供字节跳动豆包的全套AI能力。

## ✨ 主要功能

### 核心功能
- **🗨️ 文本对话**：支持与豆包AI进行智能对话
- **🎨 图片生成**：支持豆包 Seedream 4.5 图片生成（每次生成4张图片）
- **🔗 引用回复**：支持引用消息内容作为生成提示词
- **⚙️ 命令触发**：支持多种命令前缀触发不同功能
- **👥 群聊/私聊**：支持在群聊和私聊中使用
- **⏱️ 每日限制**：可设置每用户每日对话次数限制

### 🆕 新功能（v2.0）

- **🚀 超能模式**：启用深度推理能力
  - 多轮搜索：自动追踪信息并持续搜索
  - 深度推理：处理复杂任务和多步骤问题
  - 浏览器操作：自动访问网页、填写表单
  - 富媒体生成：综合生成多种内容

- **🎵 音乐生成**（实验性）：一键生成歌曲
  - 支持主题描述或自定义歌词（最多200字）
  - 11种音乐风格（民谣、嘻哈、R&B等）
  - 男声/女声可选
  - 自动生成歌曲封面

- **🎙️ 播客生成**（实验性）：文档秒变播客
  - 上传PDF文件或网页链接
  - 生成双人对话播客
  - 高度自然的语音效果

## 安装方法

1. 插件已包含在 `plugins/doubao/` 目录中
2. 编辑 `plugins/doubao/config.json` 配置文件
3. 在 `plugins/plugins.json` 中启用插件
4. 重启应用

## 配置说明

编辑 `plugins/doubao/config.json`，主要配置项：

```json
{
    "conversation_id": "你的豆包会话ID",
    "cookie": "你的豆包cookie",

    "commands": {
        "chat": ["豆包", "豆", "doubao", "db"],
        "super": ["超能", "agent", "深度思考", "超能模式"],
        "music": ["音乐", "music", "作曲", "写歌"],
        "podcast": ["播客", "podcast"]
    },

    "private_chat": true,
    "group_chat": true,
    "daily_limit": 20,

    "enable_super_mode": true,
    "enable_music": false,
    "enable_podcast": false,

    "music_default_style": "民谣",
    "music_default_mood": "快乐",
    "music_default_voice": "女声"
}
```

### 基础配置

- `conversation_id`: **必需**，豆包会话ID
- `cookie`: **必需**，豆包API认证cookie
- `private_chat`: 是否允许私聊使用（true/false）
- `group_chat`: 是否允许群聊使用（true/false）
- `daily_limit`: 每用户每日对话次数限制（0表示无限制）

### 命令配置

**新版配置**（推荐）：
```json
"commands": {
    "chat": ["豆包", "豆", "doubao", "db"],          // 普通对话
    "super": ["超能", "agent", "深度思考"],           // 超能模式
    "music": ["音乐", "music", "作曲"],              // 音乐生成
    "podcast": ["播客", "podcast"]                   // 播客生成
}
```

**旧版配置**（兼容）：
```json
"commands": ["豆包", "豆", "doubao", "db"]  // 仅支持普通对话
```

### 功能开关

- `enable_super_mode`: 是否启用超能模式（默认：true）
- `enable_music`: 是否启用音乐生成（默认：false，实验性功能）
- `enable_podcast`: 是否启用播客生成（默认：false，实验性功能）

### 音乐生成参数

- `music_default_style`: 默认音乐风格（民谣、嘻哈、R&B、爵士、雷鬼、电音等）
- `music_default_mood`: 默认情绪（快乐、伤感等）
- `music_default_voice`: 默认音色（男声、女声）

## 如何获取配置参数

### 获取 conversation_id 和 cookie

1. 使用浏览器访问 https://www.doubao.com 并登录
2. 按 F12 打开开发者工具，切换到"网络"(Network) 标签
3. 在豆包页面发起一次对话
4. 找到名为 "completion" 的请求：
   - **conversation_id**: 在请求URL或响应中可以找到，格式类似 `7xxxxxxxxxxxxxx`
   - **cookie**: 在请求头(Request Headers)中找到 Cookie 字段，复制整个值

### 查找 conversation_id 的方法

- 方法1: 在浏览器地址栏查看，格式为 `https://www.doubao.com/chat/【这里就是conversation_id】`
- 方法2: 在 Network 请求的 URL 参数或 Payload 中查找

## 使用方法

### 🗨️ 基本对话

**私聊**：
```
豆包 今天天气怎么样？
```

**群聊**：
```
豆包 帮我写一首诗
```

### 🎨 图片生成

**直接生成**：
```
豆包 画一只可爱的小猫
```
- 每次请求生成 **4张图片**（豆包 Seedream 4.5）
- 机器人会依次发送4张图片到聊天窗口
- 图片自动下载并缓存

**引用回复生成**（推荐）：
1. 长按某条消息，选择"引用"
2. 在引用框中输入：`豆包`
3. 机器人会使用被引用的消息内容作为生成提示词

示例：
```
用户A: 一只金毛犬在海边奔跑，夕阳下，温暖的光线
用户B: [引用上述消息] 豆包
→ 机器人生成4张相关图片
```

超能模式启用深度推理和多轮搜索能力，适合处理复杂任务：

超能 分析一下近期人工智能领域的重要进展

**超能模式能做什么？**
- 📚 多轮搜索最新信息

### 🎵 音乐生成（✅ 已完全实现）

**基础用法**：
```
音乐 写一首关于春天的歌
作曲 夕阳下的海边，温暖而浪漫
```

**带歌词生成**：
```
音乐 歌词：窗外的雨，滴答滴答，思念在心底发芽...
```

**功能特性**：
- ✅ 支持主题描述自动生成（auto模式）
- ✅ 支持自定义歌词生成（custome_lyric模式）
- ✅ 可配置音乐风格、情绪、音色
- ⚡ 智能降级：API失败时自动切换到对话模式

**技术限制**：
- 生成时长：最多1分钟
- 歌词字数：最多200字
- 风格选择：11种（通过配置文件设置默认值）

**配置参数**：
```json
{
  "enable_music": true,
  "music_default_style": "民谣",  // 可选：民谣、嘻哈、R&B、爵士、雷鬼、电音等
  "music_default_mood": "快乐",   // 可选：快乐、伤感等
  "music_default_voice": "女声"   // 可选：男声、女声
}
```

**实现原理**：
- content_type: 2005（音乐生成标识）
- action_bar_skill_id: 9（音乐技能ID）
- 根据歌词长度自动判断生成类型

## 常见问题

### 1. 插件不响应命令？

- 检查 `plugins/plugins.json` 中 Doubao 插件是否已启用（`"enabled": true`）
- 确认 `config.json` 中的 `conversation_id` 和 `cookie` 已正确填写
- 查看日志中是否有 `[Doubao]` 相关的错误信息
- 确认命令前缀正确（默认：`豆包`、`豆`、`doubao`、`db`）
- 注意命令前缀不含#符号

### 2. API 调用失败 / 限流？

**症状**：日志显示 `rate limited` 或 `710022004` 错误

**解决方法**：
- **Cookie 过期**：重新从浏览器获取最新 Cookie
- **设备ID不匹配**：确保使用真实浏览器的 device_id 和 web_id
- **频率限制**：减少调用频率，等待几分钟后重试
- **网络问题**：检查能否访问 `https://www.doubao.com`

**如何更新Cookie**：
1. 清除浏览器缓存，重新登录 doubao.com
2. F12 → Network → 发送一条测试消息
3. 找到 `completion` 请求，复制完整 Cookie
4. 更新 `config.json` 中的 cookie 字段
5. 重启应用

### 3. 图片生成超时？

- **网页能看到图片，微信没收到**：检查日志中是否有 `[Doubao] 从creations提取图片` 的记录
- **显示"豆包响应超时"**：可能是图片生成时间过长，或API返回格式变化
- **只收到1张图**：检查日志中 `发送第2-4张图片` 是否有错误

### 4. 超出每日限制？

- 检查 `config.json` 中的 `daily_limit` 设置
- 设置为 0 可取消限制
- 重启应用会重置计数（统计数据不持久化）

### 5. 引用回复不工作？

- 确保引用格式正确：`「用户名：内容」\n---\n豆包`
- 企业微信的引用格式会自动识别
- 查看日志：`[Doubao] 检测到引用消息` 表示识别成功

### 6. 超能模式效果不明显？

- 确保 `enable_super_mode: true` 已启用
- 查看日志确认 `need_deep_think: 1` 已设置
- 超能模式适合复杂任务，简单问题可能看不出差异
- 尝试提出需要多步骤推理或信息搜索的问题

### 7. 音乐/播客生成功能无法使用？

**功能状态**：✅ 这两个功能已完全实现（v2.1.0）

**启用步骤**：
1. 在配置文件中设置 `enable_music: true` 或 `enable_podcast: true`
2. 确保cookie和conversation_id配置正确
3. 直接使用触发词即可

**音乐生成示例**：
```
音乐 写一首关于春天的歌
作曲 歌词：窗外的雨滴答滴答...
```

**播客生成示例**：
```
播客 https://cloud.tencent.com/developer/news/2592222
podcast 人工智能的发展历史和未来趋势
```

**故障排查**：
- 查看日志中 `[Doubao] 开始生成音乐/播客` 确认功能触发
- API失败会自动降级到对话模式
- 检查Cookie是否过期

## 注意事项

- Cookie 包含敏感信息，请妥善保管，不要泄露
- Cookie 有有效期，过期后需要重新获取
- 频繁调用可能触发豆包的频率限制
- 本插件仅供学习交流使用
