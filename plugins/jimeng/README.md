# 即梦AI插件

## 简介

即梦AI插件是一个用于dify-on-wechat项目的插件，支持通过即梦AI API生成图片和视频。

## 功能特性

- ✅ **图片生成**：支持文本生成图片（文生图）
- ✅ **视频生成**：支持文本生成视频（文生视频）
- ✅ **多模型支持**：支持即梦AI的多个模型版本
- ✅ **优先级控制**：高优先级插件，优先处理生成请求

## 安装配置

### 1. 获取Session ID

1. 访问即梦AI官网：https://jimeng.jianying.com/ai-tool/image/generate
2. 登录后，打开浏览器开发者工具（F12）
3. 切换到"Application"或"存储"标签
4. 找到Cookies中的`sessionid`值
5. 复制该值用于配置

### 2. 配置插件

在 `plugins/jimeng/` 目录下创建 `config.json` 文件：

```json
{
  "enabled": true,
  "jimeng_api_base": "http://113.45.68.49:8008",
  "jimeng_session_id": "你的sessionid",
  "jimeng_image_model": "jimeng-4.0",
  "jimeng_video_model": "jimeng-video-3.0",
  "jimeng_image_size": "1:1",
  "jimeng_video_resolution": "1080p"
}
```

### 3. 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `enabled` | 是否启用插件 | `true` |
| `jimeng_api_base` | 即梦AI API地址 | `http://113.45.68.49:8008` |
| `jimeng_session_id` | 即梦AI的Session ID（必填） | 空 |
| `jimeng_image_model` | 图片生成模型 | `jimeng-4.0` |
| `jimeng_video_model` | 视频生成模型 | `jimeng-video-3.0` |
| `jimeng_image_size` | 图片尺寸比例 | `1:1` |
| `jimeng_video_resolution` | 视频分辨率 | `1080p` |

### 4. 可用模型

**图片生成模型：**
- `jimeng-4.0`
- `jimeng-3.1`
- `jimeng-2.1`

**视频生成模型：**
- `jimeng-video-3.0`
- `jimeng-video-2.0`

**图片尺寸：**
- `1:1` - 方形
- `16:9` - 横屏
- `9:16` - 竖屏
- `4:3` - 标准横屏
- `3:4` - 标准竖屏

**视频分辨率：**
- `1080p`
- `720p`
- `480p`

## 使用方法

### 基本用法

插件通过检测消息中的"**即梦**"关键词来触发生成功能。

**1. 直接生成图片**

在微信中发送：
```
即梦 一只可爱的小猫
即梦 梦幻的森林景色
即梦 未来城市
```

**2. 生成视频**

在消息中包含视频相关关键词（视频、动画、动起来、运动、移动等）：
```
即梦 一只狗在草地上奔跑的视频
即梦 海浪拍打礁石的动画
即梦 让这个场景动起来
```

**3. 引用消息生成**

引用之前的任何一条消息，然后回复：
```
即梦
```

系统会自动提取引用的内容作为生成描述。

### 使用场景示例

**场景1：直接描述生成**
```
用户：即梦 一只在花园里玩耍的小狗
机器人：[返回生成的图片]
```

**场景2：视频生成**
```
用户：即梦 夕阳西下的海滩视频
机器人：[返回生成的视频]
```

**场景3：引用消息生成**
```
用户A：一座被雪覆盖的山峰
用户B：[引用用户A的消息] 即梦
机器人：[根据"一座被雪覆盖的山峰"生成图片]
```

### 自动判断类型

插件会根据描述内容自动判断是生成图片还是视频：

- **包含这些关键词时生成视频**：视频、动画、动起来、运动、移动
- **其他情况生成图片**

您也可以通过修改代码中的 `video_keywords` 列表来自定义触发视频生成的关键词。

## 工作原理

1. 插件监听所有文本消息（TEXT类型）
2. 检测消息中是否包含"即梦"关键词
3. 如果是引用消息格式，提取被引用的内容
4. 根据内容中的关键词判断生成图片还是视频
5. 调用即梦AI API进行生成
6. 返回生成的图片/视频URL

## 注意事项

1. **Session ID有效期**：Session ID会过期，需要定期更新
2. **免费额度**：即梦AI每天提供66点免费额度
3. **仅供个人使用**：请遵守即梦AI的使用条款，不要用于商业用途
4. **API部署**：需要先部署即梦AI API服务（jimeng-free-api-all项目）
5. **触发关键词**：只有包含"即梦"的消息才会触发插件
6. **引用消息格式**：支持企业微信的引用消息格式

## 故障排除

### 插件不生效
1. 检查 `config.json` 中的 `enabled` 是否为 `true`
2. 检查 `jimeng_session_id` 是否已配置且有效
3. 查看日志确认插件是否正确加载

### 生成失败
1. 检查即梦AI API服务是否正常运行
2. 检查Session ID是否已过期
3. 检查网络连接是否正常
4. 查看日志中的详细错误信息

### Session ID过期
1. 重新登录即梦AI官网
2. 获取新的Session ID
3. 更新 `config.json` 中的配置
